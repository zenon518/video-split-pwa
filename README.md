# 動画ぶんかつ

長い動画を、5分以内の動画に自動で分けるPWAです。再エンコードなし。動画は端末の外に出ません。

## GitHub Pagesに置く手順

1. GitHubで新しいリポジトリを作る(名前は自由)
2. このフォルダの中身をすべてアップロードする(`index.html` がリポジトリの一番上に来る形)
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に出る `https://ユーザー名.github.io/リポジトリ名/` をiPhoneのSafariで開く
5. 共有ボタン → 「ホーム画面に追加」

## 使い方

1. 「ファイルから動画を選ぶ」→「ファイルを選択」から、iPhoneの「ファイル」にある動画を選ぶ
2. 自動で分割位置が決まり、各パートの長さが出る
3. 「まとめて保存」→ 共有画面で「ビデオを保存」

## 仕組みと制限

- 切れ目は直前のキーフレームに合わせます。各パートは目標より数秒ずれます。
- 対応形式は MP4 / MOV(iPhoneで撮った動画はこの形式です)。
- キーフレームから始まらない形式(オープンGOPのHEVCなど)では、切れ目の直後のコマが数枚欠けることがあります。


## v2 修正内容（長い動画向け）

- 分割の進み具合を「1 / 5 本目」のように表示します。
- 連続する動画データをまとめ、分割処理で作る管理情報を小さくしました。
- 長い動画の処理中、iPhoneの画面更新が止まりにくいよう改善しました。
- iOSのメモリ制限や未対応の動画形式で失敗する場合はあります。すべての長尺動画で成功する保証はありません。

### 既にGitHub Pagesへ公開している場合

このZIPを展開し、リポジトリのルートに同名ファイルをアップロードして置き換えてください。
上書き後にSafariでページを再読み込みし、ホーム画面アプリを一度閉じて再度開いてください。

## v3: iPhone の写真選択で無反応になる場合

- 動画を選ぶ際に「動画を選択中です」と表示します。
- 写真選択画面が `cancel` イベントを返したときは、分割処理に入っていないことと考えられる原因を画面に表示します。
- 同じ動画を再度選べるようにします。
- **重要:** iPhone の写真ピッカー内の動画準備失敗を Web アプリから修正することはできません。WebKit 側の不具合や端末の空き容量などが関係する場合、v3 でも動画は読み込めません。この更新は診断・説明の改善であり、写真からの直接読み込みが必ず成功する修正ではありません。

## v4: ファイル経由で動画を渡す

- 写真ライブラリから動画を選ばず、iPhone「ファイル」からMP4 / MOV / M4V動画を選択します。
- ファイル選択のフィルタを外し、動画かどうかはアプリ側で確認します。
- iOSの仕様により、ファイル選択メニューに写真ライブラリが併記されることはあります。その場合は**「ファイルを選択」**をタップしてください。
- 写真アプリ内にしかない動画は、あらかじめ「ファイル」に保存されている必要があります。
- 動画の分割エンジンはv2と同じです。端末容量・コーデック・メモリ上限などによる失敗は残る可能性があります。
- 既存のGitHub Pagesへは、このZIPの中身をリポジトリ直下に上書きします。

## v5: iPhone標準のファイル選択に変更

- 透明な1pxのファイル入力をラベルで起動する方式を廃止し、`input type="file"` を画面上にそのまま表示しました。iPhoneの標準のファイル選択ボタンを直接押せます。
- `accept` の制限は付けず、選択後に拡張子/種類をチェックします。
- iPhoneのファイル選択操作でファイルをアプリが受け取ったかを画面に表示します。
- iOS/WebKit側のファイルピッカー不具合やクラウド側ファイル未取得などについて、必ず読み込める保証はありません。
- GitHub Pagesでは解凍した9ファイルをリポジトリ直下に配置してください。既存サイトにアップロードしただけではなく、変更の保存（Commit changes）が必要です。
